# Fonts

`PretendardVariable-kr.woff2` — Pretendard Variable (weights 45–920) by Kil Hyung-jin, SIL Open Font License 1.1
(https://github.com/orioncactus/pretendard/blob/main/LICENSE). Subset for this site: Latin, punctuation, Hangul jamo,
the 2,350 KS X 1001 syllables plus every syllable used in the site's pages (448 KB instead of 2 MB).
Characters outside the subset fall back to the system font. Regenerate with fontTools `pyftsubset` if needed.
