# ADR-0003: 모바일 로컬 데이터베이스 — 단계적 도입 (M0: 스냅샷 캐시 → M2: Drift)

- 상태: 채택됨 (M0 부분 구현)
- 날짜: 2026-08-06

## 결정

- **Milestone 0 (구현됨)**: `CouponCache` 인터페이스 + SharedPreferences JSON
  스냅샷. 마지막 성공 응답과 동기화 시각을 저장하고, 네트워크 실패 시
  `fromCache` 표시와 함께 제공한다.
- **Milestone 2 (갱신됨)**: 오프라인 검색·필터·정렬은 전체 스냅샷 + 로컬
  쿼리 적용으로, 사용 완료 임시 처리는 PendingActionQueue로 해결되어 Drift
  없이 M2 요구를 충족했다. Drift(SQLite) 도입 시점은 양방향 필드 동기화·부분
  갱신이 필요한 M3+로 조정한다.

## 근거

- M0의 요구는 "목록 오프라인 폴백" 하나다. Drift+코드젠을 지금 도입하면
  기반 단계의 복잡도만 커진다.
- 인터페이스(`CouponCache`)를 먼저 고정했으므로 구현 교체 시 리포지토리·UI
  변경이 없다.

## 결과

- 바코드 페이로드 등 민감 데이터는 스냅샷 캐시에 저장하지 않는다
  (M2에서 flutter_secure_storage로 분리).
