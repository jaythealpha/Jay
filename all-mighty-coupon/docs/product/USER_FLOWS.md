# User Flows

## 구현된 흐름 (Milestone 0)

### 앱 실행 → 서버 상태 확인

1. 앱 실행 → 홈(Foundation) 화면
2. `GET /health` 자동 호출 → 서버/DB/Redis 상태 표시
3. 실패 시 사용자 메시지 + "다시 시도"

### 쿠폰함 열람 (온라인)

1. 홈 → "쿠폰함 열기"
2. `GET /v1/coupons` → 유효기간 빠른 순 목록
3. 카드: 브랜드 → 상품명 → D-day → 금액 → 상태(아이콘+라벨)
4. 당겨서 새로고침

### 쿠폰함 열람 (오프라인)

1. 네트워크 실패 → 마지막 동기화 스냅샷 표시
2. "오프라인 — 마지막 동기화 데이터" 배너로 캐시임을 명시
3. 캐시도 없으면 오류 화면 + "다시 시도"

## 설계된 흐름 (미구현 — 이후 마일스톤)

### 쿠폰 등록 (M1) — Three-Second Capture

쿠폰 화면 → 공유 → All Mighty Coupon → 자동 등록
또는 앱 실행 → 등록 → 이미지 선택.
등록 후: PROCESSING → 분석 → ACTIVE 또는 NEEDS_REVIEW.

### 추출 확인 (M1) — Confirm, Do Not Type

분석 완료 → 필드별 신뢰도와 함께 표시 → 사용자는 확인/수정만.
유효기간 신뢰도 <0.95면 반드시 확인 요구.

### 중복 감지 (M1)

"이미 등록된 쿠폰과 비슷합니다" → 기존 쿠폰 보기 / 새 쿠폰으로 등록 / 등록 취소.
자동 삭제하지 않음.

### 사용 완료 / 복구 (M2)

상세 → 바코드 표시(밝기↑, 확대, 오프라인 지원) → 사용 완료(REDEEMED)
→ 명시적 복구 시 유효기간 기준 상태 재계산.

### 만료 알림 (M3)

30/7/3/당일 09:00 알림 → 쿠폰 보기 / 사용 완료 / 하루 뒤 다시 알림.
