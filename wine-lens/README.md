# 🍷 와인 렌즈 (Wine Lens)

술 라벨을 카메라로 찍으면 **주종을 자동 판별**하고, **연식 · 가격대 · 히스토리 · 스토리 · 생산자 정보**와
애호가에게 유용한 **테이스팅 노트 · 음식 페어링 · 서빙/보관 팁**을 **세션별 인포그래픽**으로 정리해 주는 웹 앱입니다.

지원 주종 (12종): 🍷 와인 · 🍶 사케 · 🥃 위스키 · 🏺 한국 전통주 · 🍺 맥주 · 🍇 브랜디(코냑) · 🏮 중국 백주 · 🌵 데킬라 · 🏴‍☠️ 럼 · 🌿 진 · 🍾 소주(희석식) · 🍸 기타 스피릿

주종마다 화면이 달라집니다:
- **맛 프로필 축** — 와인: 바디/탄닌/산도/당도 · 사케: 단맛(甘辛)/산미/바디/향 · 위스키: 바디/피트/단맛/스파이스 · 전통주: 단맛/산미/바디/탄산 · 맥주: 바디/쓴맛/단맛/탄산 · 브랜디: 바디/과실향/단맛/오크 · 백주: 향 강도/단맛/부드러움/여운 · 데킬라: 바디/아가베향/단맛/스파이스 · 럼: 바디/단맛/오크/스파이스 · 진: 주니퍼/시트러스/플로럴/스파이스 · 소주: 부드러움/단맛/알코올감/깔끔함
- **제원(Specs)** — 사케: 분류/정미보합/일본주도 · 위스키: 숙성 연수/캐스크 · 맥주: 스타일/IBU/발효 · 브랜디: 등급(VS/VSOP/XO) · 백주: 향형(농향/장향/청향) · 데킬라: 등급(블랑코/레포사도/아녜호) · 럼: 숙성·솔레라/원료(당밀·즙) · 진: 스타일/시그니처 보태니컬 · 소주: 희석식·증류식 구분 등
- 섹션 명칭도 주종에 맞게 (와이너리/양조장/증류소/브루어리/메종, 포도 품종/원료/보태니컬 등)

> 이 프로젝트는 저장소의 게임과 별개인 **독립 앱**입니다. `wine-lens/` 폴더만으로 완전히 동작합니다.

## ✨ 특징

- 📷 **라벨 스캔** — 카메라 실시간 촬영 또는 갤러리 사진 불러오기 (모바일 후면 카메라 우선, 촬영 가이드 프레임)
- 🤖 **AI 라벨 인식 + 주종 자동 판별** — Claude 비전 모델이 라벨에서 주종을 판별하고 정보를 구조화 (Sonnet 5 / Opus 4.8 / Haiku 4.5 선택)
- 📊 **인포그래픽** — 라벨 플레이트 히어로, KPI 타일, 주종별 맛 프로필 스케일, 가격 티어 미터, 음용 적기 타임라인, 히스토리 타임라인
- 🗂️ **세션 기록** — 스캔할 때마다 하나의 세션으로 저장(주종 아이콘 표시). 사이드 드로어에서 썸네일과 함께 다시 열람/삭제
- 🔒 **프라이버시** — API 키와 스캔 기록은 **브라우저(localStorage)에만** 저장. 별도 백엔드/서버 없음
- 🧪 **데모 모드** — API 키 없이 탭할 때마다 12종 샘플 순환: 샤토 마고 → 닷사이 23 → 맥캘란 12 → 복순도가 → 기네스 → 헤네시 VSOP → 마오타이 → 돈 훌리오 → 사카파 23 → 헨드릭스 → 진로 이즈백
- 📤 **공유** — 결과를 시스템 공유 시트 또는 클립보드로 내보내기
- 빌드/설치 불필요 — 순수 HTML/CSS/JS 단일 파일

## 🚀 실행하기

브라우저에서 `wine-lens/index.html`을 열기만 하면 됩니다. 단, **카메라(getUserMedia)는 보안 컨텍스트**가
필요하므로 로컬 서버(또는 HTTPS)에서 실행하는 것을 권장합니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/wine-lens/ 접속
```

GitHub Pages로 배포된 경우: `https://<user>.github.io/<repo>/wine-lens/`

## 🔑 실제 라벨 인식 켜기 (선택)

1. [console.anthropic.com](https://console.anthropic.com/settings/keys) 에서 API 키 발급
2. 앱 우상단 **⚙️ 설정** → API 키 입력 → 저장
3. 이제 라벨을 촬영하면 실제 인식이 동작합니다

> 키는 브라우저에서 Anthropic API로 **직접** 호출됩니다(`anthropic-dangerous-direct-browser-access`).
> 공유 기기에서는 사용을 피하고, 개인용 키만 등록하세요. 데스크톱/모바일 브라우저 CORS 정책에 따라
> 직접 호출이 차단되면 데모 모드로 UI를 확인할 수 있습니다.

## 🗂️ 세션 개념

- **한 번의 스캔 = 한 세션.** 촬영 사진, 인식 시각, 인식 결과(JSON)가 함께 저장됩니다.
- 최근 40개까지 보관하며, 오래된 세션은 자동으로 밀려납니다.
- 각 세션은 언제든 다시 열어 인포그래픽 전체를 볼 수 있습니다.
