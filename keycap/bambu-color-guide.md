# 🎨 키캡 3D 모델에 색 입히기 — Bambu Studio 가이드

3D 프린터(FDM)는 텍스처를 그대로 풀컬러로 인쇄하지 못해요. 색을 내려면 **몇 개의 필라멘트 색으로 칠해서(페인팅)** 인쇄해야 합니다. 두 가지 길이 있어요.

---

## 길 A — 도구가 만든 "색상 포함 3mf" 사용 (가장 쉬움) ⭐

키캡 리사이저 도구에 **GLB 파일을 넣으면**, 텍스처 색이 입혀진 `.3mf`가 나와요. 이걸 Bambu Studio가 자동으로 필라멘트 색으로 변환해 줍니다.

1. 도구(웹)에 **원본 GLB**(Meshy에서 텍스처 포함으로 다운로드)를 끌어넣기 → **변환 실행** → `*_1u.3mf` 다운로드
2. **Bambu Studio**에서 그 `.3mf`를 **열기(Open)**
3. "**Color Parsing(색상 인식)**" 또는 "**이 파일의 색상을 적용하시겠습니까?**" 창이 뜨면 → **예/적용**
   - Bambu가 모델의 색을 **AMS 필라멘트 슬롯**에 자동 매핑해요.
4. 색 수가 많으면, 오른쪽 **필라멘트 개수**를 2~4개로 줄여 단순화 (인쇄 현실에 맞게)
5. 슬라이스 → 인쇄. AMS가 있으면 자동 색 교체, 없으면 색마다 일시정지 후 수동 교체.

> 💡 텍스처는 색이 수백 개라, Bambu가 비슷한 색끼리 묶어 필라멘트 수에 맞춥니다. 필라멘트 2~4색이 현실적이에요.

---

## 길 B — 흰색 모델에 직접 손으로 칠하기 (정밀 제어)

색 데이터가 아예 없는 흰색 `.3mf`(또는 STL)를 직접 칠하는 방법이에요.

1. Bambu Studio에서 모델 열기 (흰색 단색 상태)
2. 왼쪽 도구막대에서 **🖌 Color Painting (색칠, 단축키 `M`)** 선택
3. 위쪽에서 **필라멘트(색) 선택** → 원하는 부위를 마우스로 칠하기
   - **Brush(붓)**: 자유롭게 칠하기 (브러시 크기 조절 가능)
   - **Fill(채우기, 스마트필)**: 각도/색 경계 기준으로 면 단위 한 번에 채우기
   - **Bucket(영역 채우기)**: 연결된 면을 한 번에
   - 잘못 칠하면 위쪽 **필라멘트 1번(기본)**으로 다시 칠해 지우기
4. 부위별로 색 반복 (예: 몸통 1색, 무늬/뿔 다른 색)
5. 슬라이스 → 인쇄

> 💡 키캡은 작아서(18mm) 디테일 색칠이 까다로워요. **Fill(스마트필)** 로 큰 면을 빠르게 칠하고 세부만 Brush로 다듬는 걸 추천.

---

## 인쇄 팁 (멀티컬러 키캡)
- **AMS 있음**: 색 자동 교체 → 가장 편함. 필라멘트 색을 실제 AMS 슬롯 색과 맞추세요.
- **AMS 없음**: "필라멘트 교체 시 일시정지"로 색마다 수동 교체. 색 수는 2개 정도로 최소화.
- 작은 키캡은 **레진(SLA)**이 디테일이 좋지만, 레진은 멀티컬러가 어려워요(단색 후 도색이 일반적).
- 색 경계가 또렷하길 원하면, 색이 바뀌는 면을 **수평(레이어 경계)**에 맞춰 배치.

---

## 요약
| 상황 | 추천 |
|---|---|
| 원본 GLB(텍스처) 있음 | **길 A** — 도구로 색상 3mf 생성 후 Bambu Color Parsing |
| 색을 내가 직접 지정하고 싶음 | **길 B** — Bambu Color Painting(M)으로 수동 칠하기 |
| 그냥 단색이면 충분 | 흰색(혹은 원하는 필라멘트 1색) 그대로 인쇄 |
