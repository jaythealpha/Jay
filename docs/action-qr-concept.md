## 1. 컨셉

**"물건에 붙이는 프로그래머블 QR."**
QR 하나를 *열쇠*로 보고, 찍었을 때 일어날 일을 사용자가 **조건 → 행동** 블록으로 설계한다.
QR은 무작위·추측 불가능한 ID를 갖고, 인쇄한 뒤에도 동작을 바꿀 수 있다.

예)
- 냉장고에 붙인 QR: 처음 찍으면 사진 저장 → 다시 찍으면 그 사진을 보여 줌.
- 선물 상자 QR: 생일 0시 전엔 카운트다운, 이후엔 영상 메시지.
- 침대 옆 QR: 찍으면 집중(잠금) 시작 → 아침 7시 또는 거실 QR을 찍어야 해제.

### 원칙
1. **QR = 영구 주소, 동작 = 언제든 교체.** QR에는 `https://<site>/a/<id>`만 담는다(짧고 스캔 쉬움).
2. **웹에서 먼저, 앱에서 더 강하게.** 같은 규칙(JSON)을 웹 런타임과 전용 앱이 함께 해석한다. 앱 전용 행동은 웹에서 "앱이 있으면 실행" 대체 화면을 보여 준다.
3. **주인과 방문자는 다르게.** 같은 QR이라도 주인이 찍으면 기록·편집, 남이 찍으면 공개 동작.
4. **개인정보 기본값은 최소.** 사진·메모는 기본 "이 폰에만"; 서버 공유는 동의 후. 위치는 비교만 하고 저장하지 않는다.
5. **실패해도 막히지 않는다.** 조건이 안 맞으면 이유와 다음 행동(언제 열리는지, 비밀번호 입력 등)을 보여 준다.

## 3. 추가 제안 기능 (오너 확인 대상)

1. **주인/방문자 모드** — 같은 QR을 주인이 찍으면 편집·기록, 방문자는 공개 동작.
2. **분실물·미아방지 태그** — 찍은 사람이 번호 노출 없이 주인에게 메시지·위치를 보냄(가방, 반려동물, 아이 이름표).
3. **루틴·습관 체크** — 약 먹기·물 마시기·운동 QR. 찍으면 기록, 정해진 시간에 안 찍으면 알림(알림은 앱/웹 푸시 단계).
4. **공유 보관함·릴레이** — 가족·커플·팀이 같은 QR에 사진/메시지를 이어 붙임(롤링페이퍼, 방명록, 여행 앨범).
5. **보물찾기·스탬프 체인** — 여러 QR을 순서대로 찍으면 최종 보상(행사, 교육, 매장 투어). 기존 쿠폰·추첨과 연결.
6. **원격 관리** — 분실·유출 시 즉시 비활성화, 만료일, 내용 교체, 스캔 통계.
7. **템플릿 갤러리** — 선물 상자, 디지털 디톡스, 보물찾기, 분실물 태그, 약 복용, 타임캡슐, 비밀 일기를 한 번에 시작.
8. **웹훅·스마트홈** — 찍으면 IFTTT/Home Assistant/Slack 호출(조명 켜기, 출근 체크).
9. **함께 묶기** — 잠금 QR과 해제 QR을 쌍으로 생성(침대 옆 ↔ 현관), 해제 QR을 일부러 먼 곳에 두는 디톡스 장치.
10. **NFC 겸용** — 앱 단계에서 같은 ID를 NFC 태그에 기록해 터치로도 동작.

## 4. 아키텍처 (앱까지 고려한 결정)

### 4.1 주소와 앱 연결
- QR 내용: `https://jay-inky.vercel.app/a/<id>` (`id` = 10자 base32, 무작위). `vercel.json` rewrite로 `/a/:id` → `action.html?i=:id`.
- **앱 단계**: 같은 경로를 iOS Universal Links(`/.well-known/apple-app-site-association`, `paths: ["/a/*"]`)와 Android App Links(`/.well-known/assetlinks.json`)로 연결 → 앱이 설치돼 있으면 **카메라로 찍는 즉시 앱이 열리고**, 없으면 웹이 열린다. 이미 인쇄된 QR도 그대로 앱과 호환된다. ⇒ 지금부터 이 경로 형식을 고정할 것.

### 4.2 데이터
| 저장소 | 내용 |
|---|---|
| Blob `aq/<id>.json` | 액션 정의(규칙), 주인 키 해시, 생성/수정 시각, 활성 여부 |
| Blob `aq/<id>/v/<rand>.webp` | 서버 보관함 항목(동의한 경우) + `aq/<id>/v/index.json` |
| KV(Upstash) `aq:<id>:n`, `aq:<id>:once:<device>`, `aq:<id>:seq:<device>` | 전체 스캔 수, N번째 판정, 1회용, 순서 진행 — **원자적 카운터 필요 → KV 필수** |
| 기기 `localStorage` | 이 폰 전용 보관함(IndexedDB), 기기 ID(무작위), 주인 키, 집중 타이머 기록 |

- **주인 인증**: 생성 시 `ownerKey`(무작위 32바이트)를 만들어 해시만 서버에 저장. 키는 만든 브라우저에 보관 + "관리 링크(키 포함)"를 저장/공유할 수 있게 제공. 앱 단계에서는 계정 로그인으로 이전.
- **방문자 기기 ID**: 무작위 UUID를 기기에 저장(개인 식별 정보 아님). 1회용·순서 판정에 사용.

### 4.3 규칙 형식 (`v:1`) — 웹과 앱이 공유
```json
{
  "v": 1, "id": "k3m9x2p7qa", "t": "냉장고 추억 상자", "c": "ff4d8d", "on": true,
  "owner": "<sha256(ownerKey)>",
  "rules": [
    { "if": [{ "who": "owner" }],               "do": [{ "a": "vault.add", "src": "camera", "scope": "device" }] },
    { "if": [{ "time": { "from": "2026-12-24T00:00+09:00" } }], "do": [{ "a": "vault.show", "mode": "latest" }] },
    { "if": [],                                 "do": [{ "a": "countdown", "to": "2026-12-24T00:00+09:00", "msg": "크리스마스에 열려요" }] }
  ]
}
```
- 규칙은 **위에서부터 첫 번째로 조건을 모두 만족한 규칙**이 실행된다(마지막 빈 조건 = 기본값).
- **조건(`if`)**: `who`(owner/visitor), `first`(this device / anyone), `count`(전체 n번째, 범위), `time`(from/to), `hours`(시간대), `days`(요일), `pass`(비밀번호 — 서버에서 해시 비교), `near`(위도·경도·반경 m), `seq`(체인 ID·단계), `device`(ios/android), `app`(앱에서 열림 여부).
- **행동(`do`)**: `show`(제목·본문·이미지·영상), `link`, `vault.add` / `vault.show`, `countdown`, `coupon`(AR 이벤트 연결), `wifi`, `contact`, `calendar`, `map`, `call`, `focus.start`(분·해제 조건: 시각/다른 QR), `focus.end`, `notify.owner`, `webhook`, `shortcut`(iOS 단축어 이름), **앱 전용** `apps.block`(앱 목록·해제 조건), `apps.unblock`, `device.lock`.
- 앱 전용 행동을 웹에서 만나면: "이 동작은 ○○ 앱에서 실행돼요" + 설치 링크 + 가능한 웹 대체(예: `focus.start` 서약형 타이머).
- 조건 판정 위치: 비밀번호·횟수·순서·주인 판정은 **서버**(`/api/action`), 시간·위치·기기 조건은 클라이언트에서 사전 판정 후 서버가 재확인(시간은 서버 시계 기준).

### 4.4 API (`api/action.js`, 의존성 없음)
| 호출 | 설명 |
|---|---|
| `POST {op:"create", def}` | ID 발급, 정의 저장 → `{id, ownerKey}` |
| `POST {op:"update", id, ownerKey, def}` | 주인만 |
| `POST {op:"scan", id, device, ctx:{pass?, lat?, lng?, app?}}` | 규칙 평가 → 실행할 행동 목록(+ 카운터 갱신) |
| `POST {op:"vault.add", id, device, data}` / `GET ?vault=<id>` | 서버 보관함(동의된 QR만) |
| `POST {op:"disable", id, ownerKey}` | 원격 비활성화 |
| `GET ?stats=<id>&k=<ownerKey>` | 스캔 통계 |
- 남용 방지: IP·기기별 rate limit(KV), 비밀번호 시도 제한, 보관함 용량·개수 제한, 업로드 이미지 자동 축소.

### 4.5 화면
- **스튜디오 "액션 QR" 탭**(`qr-studio.html`): 템플릿 선택 → 블록 편집(조건/행동 카드) → 미리보기(가상 스캔: 주인/방문자, 날짜 바꿔 보기) → QR 디자인(기존 스튜디오) → 관리 링크 저장.
- **런타임 `action.html`**: 스캔 → 서버 평가 → 행동 실행. 실패/잠김 상태는 이유와 열리는 조건 표시.
- **앱**: 같은 규칙 해석기 + 앱 전용 행동. 스캐너 내장, Universal/App Links, 푸시, 위젯(집중 남은 시간).

### 4.6 전용 앱 기술 선택 (권장)
- **React Native(Expo) + 네이티브 모듈**: 규칙 해석기를 TS 하나로 웹·앱 공유. 차단 기능은 네이티브 모듈
  - iOS: `FamilyControls`(앱 선택 UI, 개인 인증 `.individual`), `ManagedSettings`(Shield로 차단), `DeviceActivity`(시각 기반 해제). **Family Controls (Distribution) 엔타이틀먼트를 애플에 신청**해야 배포 가능.
  - Android: `AccessibilityService` 또는 `UsageStatsManager` + 오버레이로 차단, 정확한 시각 해제는 `AlarmManager`. 접근성 API 사용 목적을 플레이 콘솔에 신고·심사.
- 참고 서비스: Brick, Unpluq(물리 태그로 차단 해제), Opal(스크린타임 기반).

### 완료 조건(P1)
- 무작위 QR 생성 → 인쇄 후 규칙 변경이 즉시 반영.
- 같은 QR을 주인/방문자가 찍었을 때 다른 결과.
- 1회용·N번째가 동시 스캔에서도 정확(KV 원자 연산).
- 타임캡슐은 서버 시각 기준으로 열림(기기 시계 조작 무효).
