# POC 합격 기준

POC가 통과하면 → 프로덕션 MVP 설계로 진행.
POC가 실패하면 → 컨셉을 재조정하거나 수동 보조 비중을 늘려 재시도.

## 1. 정량 지표

테스트 데이터: 실제 아이가 그린 사람 그림 사진 10장.
다양성 확보: 연령대 3~7세, 종이/스케치북, 스마트폰으로 촬영, 조명·각도 무작위.

| # | 지표 | 측정 방법 | 목표 | 통과 |
|---|---|---|---|---|
| 1 | 인물 검출 성공률 | `drawn_humanoid_detector`가 bbox 반환한 비율 | ≥ 70% | □ |
| 2 | 자동 리깅 성공률 | 무수정 BVH 적용으로 어색하지 않게 움직이는 비율 | ≥ 50% | □ |
| 3 | 처리 시간 (CPU) | 입력→GIF까지 wall-clock | ≤ 60초/장 | □ |
| 4 | 처리 시간 (GPU) | 동일 | ≤ 10초/장 | □ |
| 5 | 출력 GIF 용량 | 파일 크기 | ≤ 2MB (모바일 전송 고려) | □ |

## 2. 정성 지표

부모 5명 블라인드 평가. 각 항목 1~5점 (3점이 통과선).

| 항목 | 질문 | 평균 |
|---|---|---|
| 인식 정확성 | "이 움직이는 캐릭터가 우리 아이가 그린 그림 같나요?" | __/5 |
| 모션 자연스러움 | "움직임이 어색하지 않나요?" | __/5 |
| 감성적 만족도 | "그림이 살아있다는 느낌이 드나요?" | __/5 |
| 공유 의사 | "이걸 가족에게 보여주고 싶나요?" | __/5 |

## 3. 실패 모드 카탈로그 (운영 중 수집)

각 실패 사례를 분류해서 어떤 보조 UI가 필요한지 결정.

- **F1**: 검출 실패 → 부모가 "여기가 캐릭터예요" 박스 그리기 UI 필요
- **F2**: 검출 OK, 관절 오인식 → 관절 끌어다 놓기 UI 필요
- **F3**: 리깅 OK, 모션 어색 → 다른 BVH 프리셋 추천 UI 필요
- **F4**: 그림이 사람 형태가 아님 → 트랙 B(생성형)로 라우팅 또는 "정물" 모드 안내

## 4. 종합 판정

- **PASS**: 정량 1·2·3 모두 통과 + 정성 평균 ≥ 3.0 → MVP 진행
- **CONDITIONAL PASS**: 정량 1·3 통과, 2가 30~50% → 수동 보조 UI 추가 후 재평가
- **FAIL**: 정량 1 < 50% → 컨셉 재조정 (예: 그림 위에 오버레이 효과만 주는 방향)
