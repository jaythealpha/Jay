# 테스트용 샘플 그림

이 디렉토리에 아이가 그린 사람 그림 사진을 넣어주세요.

## 권장 사항

- 형식: JPG 또는 PNG
- 해상도: 1024x1024 이상이면 좋음 (자동 리사이즈 됨)
- 그림: **사람 형태** (머리·몸통·팔다리 구분 가능)
- 배경: 흰 종이, 그림자 최소화. 휴대폰 정면 촬영.
- 양: 합격 기준 측정용 10장 이상

## 좋은 샘플 vs 나쁜 샘플

| 좋음 | 나쁨 |
|---|---|
| 흰 종이, 정면 촬영 | 그림자 짙음 |
| 팔다리 명확 | 막대 사람 (선이 너무 얇음) |
| 한 명만 그려짐 | 여러 명 겹침 |
| 검은/진한 색 윤곽 | 연필 흐릿 |

## 프라이버시

- 샘플은 git에 커밋하지 마세요. (`.gitignore`로 보호됨)
- 외부에 공유할 때는 부모 동의 받기.
