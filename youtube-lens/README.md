# 🎬 유튜브 렌즈 (YouTube Lens)

유튜브 영상 URL과 스크립트(자막)를 넣으면, **인터뷰이의 노하우를 요약**하고
그 프로세스를 **단계별 자동화 플레이북**으로 정리해 주는 웹 앱입니다.
"이 영상, 좋은데 나는 어떻게 따라 하지?"를 실행 가능한 액션 플랜 + 자동화 설계로 바꿔 줍니다.

> 이 프로젝트는 저장소의 게임과 별개인 **독립 앱**입니다. `youtube-lens/` 폴더만으로 완전히 동작합니다.

## ✨ 무엇을 해 주나요

영상 하나를 넣으면 다음을 한 화면에 정리합니다.

- 📝 **핵심 요약 + 3줄 TL;DR** — 영상의 결론을 먼저
- 🎙 **인터뷰이 분석** — 누구이고 왜 들을 만한지
- 🧠 **노하우 카드** — 따라 할 수 있는 형태로 카테고리별 정리 (콘텐츠제작·계정성장·수익화·플랫폼전략·운영·마인드셋)
- 🛠 **자동화 플레이북** — 프로세스를 단계로 쪼개고, 각 단계의 **자동화 난이도(🟢쉬움/🟡반자동/⚪수동/🔴불가)**·추천 도구·자동화 방법 제시
- 🤖 **자동화 파이프라인 설계** — 아이디어→제작→배포→분석→수익화 스택과 정기 실행(크론) 아이디어
- ✅ **액션 플랜 체크리스트** — 오늘 당장 / 첫 주 할 일 (체크 가능)
- ⚠️ **리스크·주의사항** — 사기 소지, 플랫폼 정책, 표시광고법 등
- 💬 **인상적인 발언** — 핵심 인용구

그리고 분석에서 멈추지 않고 **실제 콘텐츠 제작**까지 이어집니다.

### ✍️ 콘텐츠 스튜디오 (분석 → 바로 올릴 콘텐츠)

결과 화면의 **"✍️ 이 노하우로 콘텐츠 만들기"**를 누르면, 방금 뽑은 노하우를 시드로
바로 게시할 수 있는 콘텐츠를 생성합니다.

- 형식 선택: **🎞 릴스 대본 / 🖼 카드뉴스 / ⚡ 쇼츠 훅 세트**
- 주제·톤·분량 지정 → **훅 후보 · 장면(슬라이드)별 대본 · 캡션 · 해시태그 · CTA** 생성
- 개수 설정은 **결과물 벌 수**입니다(카드뉴스 "세트 수", 릴스 "대본 수" 등). 길이가 아닙니다.
  카드뉴스는 별도로 **장수**(5~15장, 기본 8장)를 지정할 수 있습니다.
- 각 콘텐츠는 **📋 전체 복사** 한 번으로 편집 도구/게시글에 붙여넣기
- **🌐 번역** — 만든 콘텐츠를 영어·일본어·중국어·스페인어로 현지화 (아래 참고)

### 🌐 콘텐츠 번역 (해외 채널용)

콘텐츠 카드의 **🌐** 버튼을 누르면 언어를 골라 번역본을 만듭니다. 번역본은 원본을 덮어쓰지 않고
**같은 프로젝트에 별도 콘텐츠로 저장**되므로, 한국어 원본과 나란히 두고 각각 편집·복사할 수 있습니다.

직역이 아니라 **현지화**입니다.

- 훅·제목·CTA는 그 언어권에서 실제로 스크롤을 멈추게 하는 표현으로 다시 씁니다
- 해시태그는 번역하지 않고 **그 언어권에서 실제로 쓰는 태그**로 교체합니다
- 영상 대본은 말할 때의 길이가 원문과 비슷하도록 맞춥니다
- 숫자·고유명사(인명·브랜드·제품명)·URL은 그대로 두고, 없는 정보를 지어내지 않습니다

번역본에는 카드와 📚 보관함에 `🇺🇸 English` 같은 배지가 붙고, 보관함 검색창에 `영어`·`English`·`日本語`처럼
언어명을 입력해 걸러낼 수 있습니다. 퀴즈의 정답 번호나 배열 순서 같은 구조는 번역 중에도 보존됩니다.

분석은 **브라우저에서 Claude API로 직접** 수행되며, 결과는 기록으로 저장되고 공유할 수 있습니다.
데모 모드에서는 콘텐츠 스튜디오도 샘플 결과로 미리 볼 수 있습니다.

## 🚀 실행하기

브라우저에서 `youtube-lens/index.html`을 열기만 하면 됩니다. 빌드·설치가 필요 없습니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/youtube-lens/ 접속
```

GitHub Pages로 배포된 경우: `https://<user>.github.io/<repo>/youtube-lens/`
(이 저장소는 `pages.yml` 워크플로로 기본 브랜치 push 시 자동 배포됩니다.)

## 🧪 데모 먼저 보기 (키 없이)

앱을 열고 **"🧪 SNS 부업 인터뷰 데모 보기"** 칩을 누르면, API 키 없이도 결과 화면 전체를
샘플 데이터(`SNS 부업` 분석)로 체험할 수 있습니다. 실제 분석 결과가 어떤 모습인지 먼저 확인하세요.

## 🔑 실제 분석 켜기

1. [console.anthropic.com](https://console.anthropic.com/settings/keys)에서 API 키 발급
2. 앱 우상단 **⚙️ 설정** → API 키 입력 → 모델 선택 → 저장
3. 유튜브 URL을 **불러오기** → 스크립트를 붙여넣거나 자동 추출 → **분석하기**

> 키는 브라우저에서 Anthropic API로 **직접** 호출됩니다(`anthropic-dangerous-direct-browser-access`).
> 공유 기기에서는 사용을 피하고 개인용 키만 등록하세요. API 키·기록은 **이 브라우저(localStorage)에만** 저장됩니다.

## 📜 스크립트(자막) — URL만 넣으면 자동

**기본은 원클릭입니다.** URL을 넣고 **분석 →**을 누르면, 앱이 유튜브 watch 페이지에서
자막 트랙(caption track)을 찾아 자동으로 스크립트를 가져온 뒤 바로 분석합니다.
**복사·붙여넣기가 필요 없습니다.**

작동 원리: 브라우저는 보안(CORS)상 `youtube.com`에 직접 요청할 수 없어서, 공개 **CORS 프록시**를
거쳐 watch 페이지 HTML → `captionTracks` → `timedtext(json3)` 순으로 자막을 추출합니다.
한국어 자막을 우선 선택하고, 없으면 영어·자동생성 자막을 사용합니다.

- 여러 개의 공개 프록시를 순서대로 시도하며, 각 요청은 타임아웃으로 보호됩니다.
- 공개 프록시가 불안정할 때를 대비해 ⚙️ 설정에서 **신뢰할 수 있는 CORS 프록시**(예:
  `https://api.allorigins.win/raw?url=`)나 **자체 프록시**를 지정하면 우선 사용합니다. 자체 프록시가 가장 안정적입니다.
- 자막이 아예 없는 영상이거나 추출이 실패하면, 입력창 아래 **"🔧 직접 붙여넣기"**가 자동으로
  펼쳐집니다. 유튜브 `⋯ 더보기 → 스크립트 표시`에서 복사해 붙여넣으면 됩니다(fallback).

```
└── README.md
```

## 📥 자동 수집 (워치리스트 → 수집함)

미리 지정한 **유튜브 채널 · 뉴스 키워드 · RSS 피드**에서 새 콘텐츠를 매일 자동으로 모아,
**관심 프로필**과 대조(Claude Haiku, 0~10점)해 유용한 것만 Notion 수집함에 쌓습니다.
앱의 📥 수집함에서 확인하고 원클릭으로 분석하세요. 데이터가 Notion에 있어 **모든 기기에서 동일**합니다.

### 🩺 소스 건강 상태

수집 때마다 소스별 결과를 워치리스트에 기록하고, 앱의 **👀 워치리스트 관리**에 표시합니다.
소스가 조용히 죽어도 알 수 없던 문제(유튜브 채널 ID가 잘못 잡혀 며칠간 0건이었는데
화면엔 아무 표시가 없었음)를 드러내기 위한 것입니다.

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 🟢 오늘 · 9건 발견 · 3건 통과 | 정상 | — |
| 🔴 연속 실패 3회 — HTTP 404 … | 소스가 죽음 | 채널 주소·RSS URL 확인 |
| 🟡 6일 전 실행 · 통과 0건 | 헛도는 소스 | 키워드를 좁히거나 관심 프로필 조정 |
| 🟡 9일 전 마지막 성공 | 한동안 새 글이 없음 | 대개 정상 |
| ⚪ 아직 수집 전 | 방금 추가 | 수집 한 번 돌려보기 |

Notion 워치리스트에 `마지막성공`·`최근결과`·`연속실패`·`누적통과` 속성으로 저장됩니다.

### 🧠 필터가 내 판정을 학습합니다

수집함에서 누른 **보관 / 제외**가 다음 수집의 채점 기준에 반영됩니다.

- **제외**는 필터가 통과시켰는데 사람이 버린 것 — 곧 필터의 오탐이므로, 비슷한 유형을 낮게 봅니다
- **보관·분석됨**은 실제로 쓸모 있었다는 확인 — 비슷한 유형을 높게 봅니다
- 최근 판정 각 12건까지를 채점 프롬프트에 예시로 넣고, 관심 프로필과 충돌하면 **판정 이력을 우선**합니다

관심 프로필 문장을 손으로 고치지 않아도 필터가 취향에 수렴합니다. 반영 현황은 수동 수집 후
**🚫 필터가 제외한 …** 박스 위에 `🧠 보관 N건 · 제외 N건을 반영했어요`로 표시됩니다.

> 검증: `node scripts/test-feedback.mjs` — 판정이 실제 채점 프롬프트에 실려 나가는지 확인합니다.
> 이 연결이 끊기면 화면상으로는 티가 안 나면서 학습만 조용히 멈춥니다.

셋업 (1회):

1. [notion.so/my-integrations](https://www.notion.so/my-integrations)에서 내부 통합 생성 → 토큰 복사
2. Notion **"유튜브 렌즈"** 페이지 → ⋯ → 연결에서 그 통합 연결 (하위 수집함·워치리스트 DB 포함)
3. Vercel → Settings → Environment Variables:
   - `NOTION_TOKEN` — 1의 토큰 (필수)
   - `ANTHROPIC_API_KEY` — 필터링·요약용 (없으면 필터 없이 전부 적재)
   - `SUPADATA_API_KEY` — 유튜브 자막 추출용
   - `APP_KEY` — (권장) 수집함 접근 잠금. 설정 시 앱 ⚙️ 설정의 "수집함 앱 키"에 같은 값 입력
   - `CRON_SECRET` — **`APP_KEY`를 설정했다면 필수.** 임의 문자열이면 되고 앱에는 넣지 않습니다.
     Vercel이 예약 실행 요청에 `Authorization: Bearer <값>`을 붙여 보내며, 이것이 없으면
     잠금 상태에서 매일 자동 수집만 401로 거부됩니다(수동 실행은 정상). 앱이 이 상태를 감지해 경고합니다.
4. 재배포 → 매일 06:00 KST 자동 수집 (앱에서 **⚡ 지금 수집 실행**으로 수동 실행 가능)

## ✍️ 자동 초안 (아침에 열면 초안까지 있는 상태)

수집·필터를 통과해 **자동 분석까지 끝난 프로젝트**에, 매일 06:30 KST에 기본 포맷 초안을 붙입니다.
분석과 초안 생성은 서버리스 60초 제한 때문에 **별도 함수·별도 크론**으로 분리돼 있습니다.

- 기본 포맷: **릴스 대본 + 요약노트** (`api/_formats.mjs`의 `DEFAULT_DRAFT_FORMATS`)
- 서버가 무인으로 만들 수 있는 포맷은 `reels` · `cards` · `summary` 3종입니다.
  분량·타깃 독자·난이도처럼 사람이 골라야 하는 포맷(블로그·퀴즈 등)은 앱에서 직접 만드세요.
- 자동 초안은 앱에서 **🤖 자동 초안 · 검토 필요** 배지로 구분됩니다.
- 끄거나 포맷을 바꾸려면 Notion 워치리스트에 `✍️ 자동 초안` **설정** 행을 만들고,
  체크를 해제(끄기)하거나 `값`에 `reels,cards`처럼 적으세요.
- 수동 실행: `/api/generate` (특정 프로젝트는 `?id=<프로젝트ID>`)

> 포맷 문구는 앱과 서버에 중복돼 있어 `node scripts/check-schema-sync.mjs`가 일치를 검사합니다.

## ▲ Vercel로 배포하기

정적 사이트라 빌드 없이 바로 배포됩니다.

1. [vercel.com/new](https://vercel.com/new) → **Import** → 저장소 선택
2. **Root Directory**를 `youtube-lens`로 지정 (Framework Preset: Other, 빌드 명령 없음)
3. **Deploy** — 이후 push할 때마다 자동 재배포

## ⚠️ 유의

- 분석은 **입력한 스크립트만을 근거로** 합니다. 스크립트가 부정확하면 결과도 부정확해집니다.
- 자동화 도구·수익화 제안은 아이디어 수준의 가이드이며, 실제 적용 전 각 플랫폼의 **약관·정책**을 확인하세요.
- 특히 SNS 부업 분야에는 과장·사기성 정보가 많습니다. 앱이 정리한 **리스크 섹션**을 꼭 함께 보세요.
- 저작권: 개인적인 학습·요약 용도로 사용하고, 원 영상의 저작권을 존중하세요.
