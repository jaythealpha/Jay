# 🎬 유튜브 렌즈 (YouTube Lens)

유튜브 영상 URL과 스크립트(자막)를 넣으면, **인터뷰이의 노하우를 요약**하고
그 프로세스를 **단계별 자동화 플레이북**으로 정리해 주는 웹 앱입니다.
"이 영상, 좋은데 나는 어떻게 따라 하지?"를 실행 가능한 액션 플랜 + 자동화 설계로 바꿔 줍니다.

> 이 프로젝트는 저장소의 게임과 별개인 **독립 앱**입니다. `youtube-lens/` 폴더만으로 완전히 동작합니다.

## ✨ 무엇을 해 주나요

영상 하나를 넣으면 다음을 한 화면에 정리합니다.

- 📝 **핵심 요약 + 3줄 TL;DR** — 영상의 결론을 먼저
- 🎙 **인터뷰이 분석** — 누구이고 왜 들을 만한지
- 🧠 **노하우 카드** — 따라 할 수 있는 형태로 카테고리별 정리 (콘텐츠제작·계정성장·수익화·플랫폼전략·운영·마인드셋)
- 🛠 **자동화 플레이북** — 프로세스를 단계로 쪼개고, 각 단계의 **자동화 난이도(🟢쉬움/🟡반자동/⚪수동/🔴불가)**·추천 도구·자동화 방법 제시
- 🤖 **자동화 파이프라인 설계** — 아이디어→제작→배포→분석→수익화 스택과 정기 실행(크론) 아이디어
- ✅ **액션 플랜 체크리스트** — 오늘 당장 / 첫 주 할 일 (체크 가능)
- ⚠️ **리스크·주의사항** — 사기 소지, 플랫폼 정책, 표시광고법 등
- 💬 **인상적인 발언** — 핵심 인용구

분석은 **브라우저에서 Claude API로 직접** 수행되며, 결과는 기록으로 저장되고 공유할 수 있습니다.

## 🚀 실행하기

브라우저에서 `youtube-lens/index.html`을 열기만 하면 됩니다. 빌드·설치가 필요 없습니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/youtube-lens/ 접속
```

GitHub Pages로 배포된 경우: `https://<user>.github.io/<repo>/youtube-lens/`
(이 저장소는 `pages.yml` 워크플로로 기본 브랜치 push 시 자동 배포됩니다.)

## 🧪 데모 먼저 보기 (키 없이)

앱을 열고 **"🧪 SNS 부업 인터뷰 데모 보기"** 칩을 누르면, API 키 없이도 결과 화면 전체를
샘플 데이터(`SNS 부업` 분석)로 체험할 수 있습니다. 실제 분석 결과가 어떤 모습인지 먼저 확인하세요.

## 🔑 실제 분석 켜기

1. [console.anthropic.com](https://console.anthropic.com/settings/keys)에서 API 키 발급
2. 앱 우상단 **⚙️ 설정** → API 키 입력 → 모델 선택 → 저장
3. 유튜브 URL을 **불러오기** → 스크립트를 붙여넣거나 자동 추출 → **분석하기**

> 키는 브라우저에서 Anthropic API로 **직접** 호출됩니다(`anthropic-dangerous-direct-browser-access`).
> 공유 기기에서는 사용을 피하고 개인용 키만 등록하세요. API 키·기록은 **이 브라우저(localStorage)에만** 저장됩니다.

## 📜 스크립트(자막)는 어떻게 넣나요

브라우저에서 유튜브 영상의 자막을 자동으로 가져오는 것은 플랫폼의 보안(CORS)·봇 차단 때문에
**항상 보장되지 않습니다.** 그래서 두 가지 경로를 제공합니다.

1. **붙여넣기 (권장·가장 정확)** — 유튜브 영상 아래 `⋯ 더보기 → 스크립트 표시`를 열고
   내용을 전체 복사해 앱의 스크립트 칸에 붙여넣습니다. 타임스탬프가 섞여 있어도 됩니다.
2. **⚡ 자동 추출 시도 (베스트 에포트)** — 공개 자막 엔드포인트에서 자동으로 시도합니다.
   실패하면(대부분 CORS) 1번으로 붙여넣으세요. 설정에서 신뢰할 수 있는 **CORS 프록시**를
   지정하면 성공률이 올라갈 수 있습니다.

## 🧱 구조

```
youtube-lens/
├── index.html   # 앱 전체 (마크업 + 스타일 + 로직, 외부 의존성 없음)
├── vercel.json  # 정적 배포 설정
└── README.md
```

## ▲ Vercel로 배포하기

정적 사이트라 빌드 없이 바로 배포됩니다.

1. [vercel.com/new](https://vercel.com/new) → **Import** → 저장소 선택
2. **Root Directory**를 `youtube-lens`로 지정 (Framework Preset: Other, 빌드 명령 없음)
3. **Deploy** — 이후 push할 때마다 자동 재배포

## ⚠️ 유의

- 분석은 **입력한 스크립트만을 근거로** 합니다. 스크립트가 부정확하면 결과도 부정확해집니다.
- 자동화 도구·수익화 제안은 아이디어 수준의 가이드이며, 실제 적용 전 각 플랫폼의 **약관·정책**을 확인하세요.
- 특히 SNS 부업 분야에는 과장·사기성 정보가 많습니다. 앱이 정리한 **리스크 섹션**을 꼭 함께 보세요.
- 저작권: 개인적인 학습·요약 용도로 사용하고, 원 영상의 저작권을 존중하세요.
