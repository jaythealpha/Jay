# 📊 SNS 부업 인터뷰 분석 — 노하우 요약 & 자동화 플레이북

> 이 문서는 **유튜브 렌즈** 앱이 SNS 부업 인터뷰 영상에서 뽑아내는 결과물의 형태를 보여 주는
> 대표 분석(데모 시드)입니다. 앱의 `🧪 데모` 버튼이 보여 주는 내용과 동일합니다.

## ⚠️ 원본 영상 접근에 대한 참고

요청하신 영상(`https://youtu.be/piUIgPTujSQ`)의 **자막을 이 개발 환경에서는 직접 가져오지 못했습니다.**
이 환경은 외부 네트워크가 차단(egress lock-down)되어 있고, 유튜브도 자동 수집을 막기 때문입니다.
그래서 접근 방식을 바꿨습니다 — **영상 하나를 수동 분석하는 대신, "영상을 넣으면 이 분석을
자동으로 만들어 주는 도구"(유튜브 렌즈 웹앱)를 만들었습니다.** 이 문서는 SNS 부업 도메인에서
일반적으로 검증된 노하우를 그 도구의 출력 형식으로 정리한 것입니다.

**요청하신 그 영상을 그대로 분석하려면:** 앱을 열고 → URL을 넣고 → 유튜브에서 `스크립트 표시`로
자막을 복사·붙여넣은 뒤 → `분석하기`를 누르면 됩니다(본인 Claude API 키 필요). 그러면 아래와
똑같은 구조의 결과가 그 영상 내용 기준으로 생성됩니다.

## 🎯 한 줄 결론

> **완벽한 콘텐츠보다, 팔리는 주제를 정하고 매일 올리는 "시스템"이 이긴다.**

## ⚡ 핵심 3줄

1. 하고 싶은 것 말고 **수요가 검증된 좁은 주제(니치)**를 골라라 — 계정 콘셉트는 한 문장으로.
2. 완성도보다 **매일 발행**이 먼저다. 잘 되는 포맷을 벤치마킹해 양으로 감각을 키워라.
3. 초반 지표는 팔로워가 아니라 **저장·공유율** — 알고리즘이 밀어주는 신호다.

## 🧠 인터뷰이의 노하우 (요약)

| 카테고리 | 노하우 | 왜 효과적인가 |
|---|---|---|
| 플랫폼전략 | **좁은 니치 + 한 문장 콘셉트**로 시작 | 주제가 좁을수록 알고리즘·사람 모두에게 계정 정체성이 각인됨 |
| 콘텐츠제작 | 잘 되는 포맷을 벤치마킹해 **양으로 감각** 만들기 | 초기엔 품질보다 반복 횟수가 알고리즘 학습·실력을 좌우 |
| 콘텐츠제작 | 첫 **1~2초 훅**에 승부 | 릴스는 초반 이탈률이 노출량을 결정 |
| 계정성장 | 지표는 **저장·공유·완주율** 중심 | 알고리즘이 "유용한 콘텐츠"로 판단해 추가 노출 |
| 수익화 | **제휴 → 디지털 상품 → 공동구매·협찬** 단계 확장 | 신뢰가 쌓이기 전 판매를 서두르면 이탈이 큼 |
| 운영·루틴 | **배치 제작 + 예약 발행** | 매일 실시간 제작은 번아웃으로 중단되기 쉬움 |

## 🛠 자동화 플레이북 (프로세스 → 자동화)

| # | 단계 | 자동화 | 도구 | 어떻게 |
|---|---|---|---|---|
| 1 | 주제·니치 리서치 | 🟡 반자동 | Sheets, ChatGPT/Claude | 인기 게시물·조회수를 시트에 모으고 LLM으로 주제·콘셉트 후보 생성 |
| 2 | 아이디어·대본 생성 | 🟢 쉬움 | Claude API, Notion | 콘셉트+포맷을 프롬프트 템플릿에 넣어 대본 20~30개 일괄 생성 → Notion 적재 |
| 3 | 제작·편집 | 🟡 반자동 | CapCut/Canva 템플릿 | 고정 템플릿에 텍스트만 교체, 자막은 자동 생성 후 교정 |
| 4 | 예약 발행 | 🟢 쉬움 | Meta 비즈니스 스위트, Buffer, Make | "발행대기" 상태를 Make가 감지해 예약 큐에 자동 등록 |
| 5 | 성과 트래킹 | 🟢 쉬움 | 인스타 그래프 API, Sheets, Looker | 지표를 매일 시트에 적재·시각화, 상위 포맷을 대본 생성에 피드백 |
| 6 | 수익화·응대 | 🟡 반자동 | ManyChat, Gumroad, Stan/Linktree | FAQ는 DM 자동응답, 판매·결제는 플랫폼 자동화, 개인화 응대만 사람 |

## 🤖 자동화 파이프라인 설계

**개요** — "아이디어→제작→배포→분석→수익화"가 한 방향으로 흐르는 **콘텐츠 공장**. Notion을 콘텐츠
DB의 중심에 두고, LLM이 리서치·대본을 채우고, Make가 상태 변화를 감지해 편집 대기·예약 발행·지표
수집을 연결한다. 사람은 **콘셉트 결정·최종 검수·개인화 응대**라는 판단 지점에만 개입한다.

```
[아이디어]  Claude/ChatGPT API + Sheets   → 키워드 리서치·대본 대량 생성
[제작]      CapCut/Canva 템플릿           → 텍스트 교체식 반자동 제작
[배포]      Make + Meta 비즈니스 스위트    → '발행대기' → 예약 발행 자동 실행
[분석]      인스타 그래프 API + Looker     → 저장·공유·완주율 매일 수집·대시보드
[수익화]    Gumroad/Stan + ManyChat       → 디지털 상품 판매 + DM 자동응답
```

**정기 실행(크론) 아이디어**
- 매주 월: 인기 게시물·해시태그 지표 수집 → 이번 주 주제 후보 자동 생성
- 매일 아침: 전날 게시물 지표 시트 적재 + 대시보드 갱신
- 매일 저녁: LLM 대본 20개 생성 → Notion 적재 배치
- 발행 시간대: 예약 큐 콘텐츠 자동 발행
- 매주 금: 상위 성과 포맷 요약 → 다음 주 대본 프롬프트에 자동 반영

## ✅ 액션 플랜

**오늘 당장**
- [ ] 관심사×수요가 겹치는 니치 3개 → 1개로 좁히기
- [ ] 계정 콘셉트를 "누구에게 어떤 가치"의 한 문장으로 확정
- [ ] 벤치마킹 상위 계정 5개 + 잘 된 릴스 10개 저장
- [ ] 훅 문구 20개를 LLM으로 생성해 리스트업

**첫 주**
- [ ] 고정 편집 템플릿 1개 + 첫 콘텐츠 7개 배치 제작
- [ ] 예약 발행 도구 세팅 (Meta 비즈니스 스위트/Buffer)
- [ ] 저장·공유·완주율 성과 시트 만들기
- [ ] 제휴 프로그램 1곳 가입 → 첫 제휴 링크 준비
- [ ] 매일 1개 발행 + 매일 지표 5분 리뷰 루틴 시작

## ⚠️ 리스크 · 주의사항

- **"월 얼마 보장" 식 과장·유료강의 유도는 사기 소지가 크다** — 검증되지 않은 수익 인증은 걸러라.
- 자동 DM·대량 팔로우 등 **과도한 자동화는 플랫폼 정책 위반**으로 계정 정지 위험.
- 제휴·협찬 콘텐츠는 **"유료 광고 포함" 표기 필수**(표시광고법).
- 성과까지 수개월이 걸릴 수 있어 **지속가능한 배치 루틴** 없이는 중도 포기하기 쉽다.
