설정

console.anthropic.com에서 발급. 브라우저에서 Anthropic API로 직접 호출됩니다(공유 기기 주의).
유튜브가 서버·프록시의 자막 다운로드를 막기 때문에, supadata.ai에서 무료 키를 발급받아 넣으면 URL만으로 안정적으로 자동추출됩니다. (키는 이 브라우저에만 저장, 자막 API 엔드포인트를 통해 사용)
서버에서 자막을 가져오는 엔드포인트. Vercel 배포판을 쓰면 같은 도메인의 /api/transcript가 자동 사용되어 비워둬도 됩니다. GitHub Pages에서 쓸 땐 여기에 Vercel 함수 주소를 넣으면 프록시 없이 안정적으로 동작해요.
위 API가 없을 때 쓰는 브라우저 폴백. 기본 공개 프록시로 시도하며, 잘 안 되면 신뢰할 수 있는 CORS 프록시 접두사를 넣으세요(예: https://api.allorigins.win/raw?url=).
