# 🏢 직장인 생존기: 월급날까지 버텨라!

직장인의 애환을 담은 선택형 생존 게임입니다.
월요일 출근부터 금요일 퇴근까지, 멘탈·체력·사회생활을 지키며 한 주를 버텨내세요.

## 🎮 플레이 방법

`index.html` 파일을 브라우저에서 열기만 하면 됩니다. 설치나 빌드가 필요 없습니다.

```bash
# 로컬 서버로 실행하려면 (선택)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 📋 게임 규칙

- **5일 × 5타임** (출근길 → 오전 업무 → 점심시간 → 오후 업무 → 퇴근 시간)마다 랜덤 이벤트가 발생합니다.
- 매 이벤트에서 선택지를 고르면 세 가지 스탯이 변합니다.
  - 🧠 **멘탈** — 0이 되면 홧김에 사직서를 던집니다
  - ⚡ **체력** — 0이 되면 번아웃으로 쓰러집니다
  - 🤝 **사회생활** — 0이 되면 면담실로 불려갑니다
- 금요일 퇴근까지 버티면 **월급날 엔딩**! 남은 스탯 합계로 점수와 칭호가 정해집니다.
- 키보드 `1` `2` `3`으로 선택, `Enter`로 진행할 수 있습니다.
- 최고 기록은 브라우저(localStorage)에 저장됩니다.
