### 🕹️ v2: 직장인 러너 — 출근 대작전

16비트 픽셀 아트 무한 러너입니다 (외부 에셋 없음 — 스프라이트는 픽셀맵, BGM/효과음은 Web Audio 칩튠 합성).

- 💰 **시급 경제**: 하루(500m) = **8시간 근무** (HUD에 09:00→18:00 시계 표시). 기본 수입은 **2026년 최저시급 10,320원 × 직급 배수** — 인턴 1.0배부터 회장 5.0배까지, 승진하면 같은 거리를 달려도 더 법니다.
- **점프** (스페이스/↑, 2단 점프 가능)로 서류더미·사무용 의자·💢부장님·커피 자국을 뛰어넘으세요.
- **슬라이드** (↓ 꾹)로 "회의중" 현수막 아래를 통과하세요.
- 💬 **카톡 폭탄**: 화요일부터 "부장님: 어디야?" 카톡이 날아옵니다. 맞으면 멘탈이 깎입니다.
- 🌆 **퇴근 전 야근 러시**: 매일 퇴근 1시간 전부터 야근 장애물(📑 긴급 보고서 탑, 🗓️ 회의 요청, ☎️ 업체 전화)이 몰려옵니다. 부딪히면 멘탈 대신 **5초간 속도 35% 감소(야근 페널티)** + 수입 차감.
- 🌙 **야근 위기 타임**: 금요일 후반엔 화면이 어두워지고 장애물이 몰려옵니다. 야식 🍗치킨도 떨어집니다. 버텨내면 "칼퇴 성공!" 보너스(시급 2시간치).
- 🛌 **주말 보너스 게임 "이불 밖은 위험해"**: 금요일을 돌파하면 15초 미니게임 진입 — 이불 쓴 김대리를 ←→로 움직여 🍗치킨·💤꿀잠은 받고, 💬업무 카톡·⏰알람·💌청첩장(축의금)은 피하세요. 끝나면 멘탈 +1 회복과 함께 "다시 월요일..."
- 💸 **스치는 월급**: 보너스 봉투(시급 1시간치)를 먹으면… 0.7초 뒤 "카드값 자동이체"로 절반이 빠져나갑니다.
- ⚡ **에너지드링크**: 4초 무적 질주 ("퇴근 본능 발동!!").
- 🪽 **레드불**: 6초간 날개가 돋아 **3단 점프** + 점프력 상승, 야근 페널티 즉시 해제 ("날개를 달았다!!").
- ☕ 커피 10잔을 모으면 멘탈(하트) 회복. **연속으로 먹으면 콤보 배율**이 올라갑니다.
- 😱 **니어미스 보너스**: 장애물을 아슬아슬하게 스치면 "아찔!" 보너스.
- 🎲 **랜덤 이벤트 4종**: 💰 보너스 타임(커피 비), 📋 보고서 마감(카톡 3연사), ☎️ 업체 전화 폭주(전화 3연속), 👀 사장님 시찰(10초간 점수 2배, 무피해 통과 시 업적).
- 🏅 **승진 메타**: 판마다 번 돈이 누적되어 인턴 → 사원 → … → 회장으로 승진하고 **시급이 인상**됩니다 (영구 저장).
- 🏆 **업적 14종**: "칼퇴의 맛", "정시 퇴근의 꿈", "날개를 달았다", "사장님 픽", "시급 인상!" 등 달성 시 토스트 알림.
- 🔰 첫 플레이 시 조작 튜토리얼, 게임오버 화면에서 📤 결과 공유 가능.
- 피격·이벤트마다 김대리 머리 위에 "퇴사 마렵다...", "야근 확정이다..." 같은 공감 말풍선이 뜹니다.
- 멘탈 3개가 모두 닳으면 번아웃으로 게임 오버. 번 돈(점수)으로 기록을 경쟁하세요.
- 모바일은 화면 탭(점프) + 좌하단 버튼(슬라이드), 주말 게임은 화면 좌/우 터치로 조작합니다.

또는 `index.html` 파일을 브라우저에서 열기만 하면 됩니다. 설치나 빌드가 필요 없습니다.

```bash

python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 📋 게임 규칙

- 시작할 때 **직급**을 선택합니다. 직급마다 시작 스탯과 고유 특성이 다릅니다.
  - 🐣 **인턴** — 체력 회복 효과 1.5배 (젊음이 무기)
  - 💼 **대리** — 출근 콤보 보너스 +5점 (꾸준함의 화신)
  - 👔 **과장** — 사회생활 감소량 절반 (짬에서 나오는 바이브)
- **5일 × 5타임** (출근길 → 오전 업무 → 점심시간 → 오후 업무 → 퇴근 시간)마다 랜덤 이벤트가 발생합니다.
- 매 이벤트에서 선택지를 고르면 세 가지 스탯이 변합니다.
  - 🧠 **멘탈** — 0이 되면 홧김에 사직서를 던집니다
  - ⚡ **체력** — 0이 되면 번아웃으로 쓰러집니다
  - 🤝 **사회생활** — 0이 되면 면담실로 불려갑니다
- 🔥 **출근 콤보** — 하루를 전 스탯 40 이상으로 마치면 콤보가 쌓이고, 콤보당 보너스 점수를 받습니다.
- 🎁 **주말 보너스 스테이지** — 금요일까지 버티면 토·일 이벤트로 최종 점수를 끌어올릴 수 있습니다.
- 최종 점수(스탯 합계 + 콤보 보너스)에 따라 칭호가 정해집니다.
- 키보드 `1` `2` `3`으로 선택, `Enter`로 진행할 수 있습니다.
- 📤 엔딩에서 결과를 공유할 수 있습니다 (모바일 공유 시트 / 클립보드 복사).
- 🔊 효과음(웹 오디오 합성)과 📳 모바일 진동을 지원하며, 우상단 버튼으로 음소거할 수 있습니다.
- 최고 기록은 브라우저(localStorage)에 저장됩니다.
